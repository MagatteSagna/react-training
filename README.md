# Formation React intensive : projet de front-end

Parcours de 2 semaines pour apprendre React.js, de zéro jusqu'à une plateforme e-learning front-end.

## Technologies
- React, Vite, JavaScript ES6+
- HTML5, CSS3
- React Router (à venir), Git/GitHub

## Avancement
- [x] Jour 1 : projet Vite, Header, Main, Footer, Badge
- [x] Jour 2 : props, listes avec map(), cartes d'étudiants
- [x] Jour 3 : useState, formulaires, gestionnaire de tâches
- [x] Jour 4 : CRUD étudiants, recherche, LocalStorage
- [x] Jour 5 : finalisation du Mini-projet B
- [x] Jour 6 : useEffect, fetch, API
- [x] Jour 7 : React Router, catalogue et page
 détail
- [x] Jour 8 : Context API, favoris et panier
- [x] Jour 9 : projet final e-learning (architecture, pages, fonctionnalités)
- [x] Jour 10 : finalisation, responsive, déploiement
## Installation et lancement
```bash
git clone https://github.com/MagatteSagna/react-training.git
cd react-training
npm install
npm run dev
```
